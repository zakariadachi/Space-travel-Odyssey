   _________SpaceVoyager-Space-Tourism-Booking-System__________


                                                          
**Description**
SpaceVoyager est une application web de réservation de voyages spatiaux qui permet aux utilisateurs d'explorer et de réserver des voyages vers différentes destinations du système solaire. L'application propose une expérience utilisateur immersive avec un design futuriste et des fonctionnalités complètes de gestion de réservations.

**Fonctionnalités Principales**
____Système d'Authentification____
  - Connexion Utilisateur : Formulaire de login avec validation front-end

  - Gestion de Session : Maintien de l'état de connexion via localStorage

  - Déconnexion : Bouton de logout avec nettoyage de session

 **Système de Réservation**

   - Formulaire Dynamique : Adaptation en temps réel selon la destination choisie

   - Calcul de Prix : Mise à jour automatique du prix total

   - Validation Client : Vérification des champs requis et formats

   - Gestion Multi-passagers : Ajout/suppression dynamique de passagers

   - Sauvegarde Automatique : Conservation des données en cours de saisie

 **Gestion des Réservations**
   - Tableau de Bord : Vue d'ensemble des réservations

   - Détails Complets : Affichage détaillé de chaque réservation

   - Tickets Imprimables : Génération de billets formatés pour impression

   - Statut des Réservations : Suivi des confirmations et statuts

**Architecture Technique**

   - Frontend : HTML5, CSS3, JavaScript vanilla

   - Styling : Tailwind CSS + CSS personnalisé

   - Stockage : localStorage pour la persistance des données

   - Design : Thème spatial avec couleurs néon et animations
